# MyWebsite

Personal site for Fanuel Gebru. Next.js App Router, TypeScript, Tailwind v4.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `src/app` routes and global styles
- `src/components` UI pieces, one component per file
- `public` static assets, including the portrait at `public/fanu.jpg`

## Checks

```bash
npm run typecheck
npm run lint
```
